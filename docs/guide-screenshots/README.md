# Illustrated guide screenshots

The guide pairs instructions with actual offline SwoLifts 1.2.0 screenshots.
`manifest.json` records source commit, APK checksum, emulator API, dimensions
and SHA-256 values for the fifteen refreshed/new guide and homepage images.
The captures use only synthetic bench/row workouts and a sample template.
No owner data or physical-device package was used.

The Settings transfer capture now shows **Share backup** and the destination-neutral
**Export to file** description; [capture provenance](share-backup.json) records
its Android source and APK/image hashes. The import-preview capture retains its
source/evidence in [WEB_WORKBENCH_01.md](../WEB_WORKBENCH_01.md).

Guide images use `GuideScreenshot`: text and image sit beside each other on
desktop and stack on mobile. Selecting an image opens the shared viewer, with
Escape/close restoring focus. The underlying link opens the original image
without JavaScript. Single-image views omit gallery next/previous controls;
the homepage retains its multi-image gallery.

The guide clearly labels the 1.2.0 preview. Capture future interface changes
from the matching app version rather than editing controls into a screenshot.
Do not put 1.2.0 screenshots into historical 1.0/1.1.1 notes as if they were
from those releases. Keep all images and their captions consistent with the
backup/restore scope and the coordinated website publication gate.
